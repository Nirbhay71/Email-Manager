# Frontend Components

**Base path**: `frontend/src/`

## Component Tree

```
main.jsx
  └── <App /> (App.jsx)
        ├── <LoadingScreen />  (inline in App.jsx)
        ├── <LoginRoute />     (inline in App.jsx)
        │     └── <GeneratedLoginPage />  (pages/LoginPage.tsx)
        │           + invisible <button> overlay for Google OAuth
        └── <DashboardRoute />  (inline in App.jsx)
              ├── <InboxPage />      (pages/InboxPage.tsx)
              ├── <AIChatPage />     (pages/AIChatPage.tsx)
              └── <ManagementPage /> (pages/ManagementPage.tsx)
```

## File Details

### `frontend/src/main.jsx`
```jsx
import ReactDOM from 'react-dom/client'
import App from './App.jsx'
ReactDOM.createRoot(document.getElementById('root')).render(<StrictMode><App /></StrictMode>)
```

### `frontend/src/App.jsx`
- **Imports**: `LoginPage.tsx`, `InboxPage.tsx`, `AIChatPage.tsx`, `ManagementPage.tsx`, `utils/api.ts`
- **State**: `user` (null=loading, false=unauthenticated, object=authenticated), `loading`
- **Custom hooks**: `usePathname()` — subscribes to `popstate` events
- **Key functions**: `parseCallbackUser()`, `navigate()`, `replacePath()`
- **Auth flow**: reads localStorage, validates via `GET /auth/me`, handles OAuth callback
- **Consumed by**: nothing (root component)
- **Consumes**: `apiFetch`, `BACKEND` from `utils/api.ts`

### `frontend/src/pages/LoginPage.tsx`
- Generated by Snitch design tool (static HTML-in-JSX)
- No direct API calls
- Rendered inside `LoginRoute` with an invisible button overlay positioned at CSS coordinates
- **Side effect**: changing this component may shift the Google button position in `App.jsx` (`top: '598px'`)

### `frontend/src/pages/AIChatPage.tsx` (26 KB — largest component)
- **API calls**: 
  - `GET /chat/sessions`
  - `POST /chat/sessions`
  - `POST /ask` (SSE streaming)
  - `GET /emails/inbox`
  - `GET /calendar/events?timeMin=...&timeMax=...`
- **State**: sessions[], activeSession, messages[], streaming, input, ...
- **SSE handling**: reads response as stream, accumulates `text_delta` chunks
- **Session persistence**: sends `sessionId` in `/ask` body to persist conversation

### `frontend/src/pages/InboxPage.tsx` (228 bytes — stub)
- Minimal implementation; not functionally complete
- Likely intended to call `GET /emails/inbox`

### `frontend/src/pages/ManagementPage.tsx` (197 bytes — stub)
- Minimal implementation; not functionally complete
- Likely intended to call `GET /categories` and `POST /categories`

## Utility

### `frontend/src/utils/api.ts`
- **Exports**: `apiFetch(path, options)`, `BACKEND`
- `BACKEND` is **hardcoded** to `'http://localhost:5000'` — must be changed for production
- **Imports from**: nothing in this repo
- **Imported by**: `App.jsx`, `AIChatPage.tsx` (and any other page making API calls)

## Styling

- `frontend/src/index.css` — imports Tailwind, custom utilities
- `frontend/src/App.css` — 48 bytes, minimal overrides  
- Inter font referenced inline in JSX (App.jsx LoadingScreen)

## Important Coupling

| Change | Side Effect |
|---|---|
| Modify `LoginPage.tsx` layout | May break Google button overlay position in `App.jsx` (top: 598px) |
| Change backend port from 5000 | Must update `BACKEND` const in `frontend/src/utils/api.ts` |
| Add new route | Must add case to `DashboardRoute` in `App.jsx` |
| Change `/auth/me` response shape | Must update `App.jsx` freshUser construction |
| Change `code: 'ACCESS_EXPIRED'` | Must update `api.ts` refresh trigger condition |
